# 📊 Garments Sales & Inventory Dashboard (2022–2024)

## 🔍 Problem Statement
Retail businesses often struggle with excess inventory and unclear sales trends.  
This project analyzes sales and inventory data to identify patterns and improve decision-making.

## 📁 Dataset
- 100,000+ rows (3 years data)
- Includes: Product, Category, Sales, Inventory, Season

## 📊 Dashboard Features
- Sales Trends (Monthly & Yearly)
- Seasonality Analysis
- Category Performance
- Top Products (Pareto Analysis)
- Inventory vs Sales Efficiency

## 📌 Key Insights
- Sales peak during Oct–Dec (festive season)
- Stable performance across years
- Sell-through rate (~2.6%) indicates overstock
- Kurti & Suit categories show similar trends

## 💡 Business Recommendations
- Reduce excess inventory
- Increase production before festive season
- Optimize stock based on demand

## 🛠 Tools Used
- Excel
- Pivot Tables
- Dashboard Design
