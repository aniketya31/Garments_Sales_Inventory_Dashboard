# Garments_Sales_Inventory_Dashboard
## 🔍 Overview
This project analyzes sales trends, seasonal patterns, and inventory efficiency.

## 📌 Key Insights
- Peak sales during festive season (Oct–Dec)
- Stable year-over-year sales trend
- Low sell-through rate (~2.6%) indicates overstock

## 🛠 Tools Used
- Excel
- Pivot Tables
- Charts & Dashboarding
